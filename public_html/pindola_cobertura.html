El gateway i el mapa de cobertura

Què fa un gateway

Un node LoRaWAN no envia els missatges a un aparell concret: els emet per ràdio i qualsevol gateway que els senti els recull. El gateway no entén el contingut: només fa de pont entre la ràdio i la xarxa de l'institut.

  1. NodeEmet un missatge curt per ràdio, a la banda EU868.
  2. GatewayRep tots els missatges que li arriben amb prou senyal i hi afegeix l'RSSI i l'SNR.
  3. XarxaEl gateway reenvia els missatges per cable o wifi fins al servidor.
  4. ServidorComprova de quin node és cada missatge, el desxifra i descarta els duplicats.

Si dos gateways senten el mateix missatge, el servidor el rep dues vegades i se'n queda un. Per això més gateways vol dir més cobertura, no dades repetides.

Per funcionar, un gateway necessita tres coses: alimentació (un endoll o un cable PoE, que porta corrent i xarxa pel mateix cable), connexió a la xarxa i estar configurat a la mateixa regió que els nodes, que a Europa és la EU868.

RSSI i SNR

Cada missatge que rep un gateway porta dues mesures de com ha arribat el senyal:

  • RSSI: la potència amb què arriba el senyal, en dBm. Sempre és negativa: com més a prop de zero, més fort. −80 dBm és millor que −110 dBm.
  • SNR: quant destaca el senyal per sobre del soroll, en dB. Pot ser positiu o negatiu: com més alt, més net.

LoRa pot rebre senyals molt febles, fins i tot per sota del soroll, però a partir d'un punt els missatges es comencen a perdre. Per valorar un senyal es miren les dues mesures:

Què fa perdre senyal

La ràdio travessa parets, però cada obstacle se'n menja una part. Dins d'un edifici, els obstacles pesen més que la distància.

  • Parets gruixudes, de formigó o de pedra.
  • Pisos i forjats: canviar de planta resta molt senyal.
  • Metall: armaris, portes metàl·liques, prestatgeries, ascensors.
  • Aigua i persones: un passadís ple de gent atenua el senyal.
  • Un gateway baix o tancat dins d'un armari.
  • Una antena tapada, inclinada o tocant una superfície metàl·lica.
RecordeuUn gateway alt i al centre de les zones que ha de cobrir sol funcionar millor que un de més potent posat en un racó.

El mapa de cobertura

Un mapa de cobertura és un plànol on es veu quin senyal arriba a cada punt des d'un gateway concret. Es fa amb un node de prova: un node que envia missatges sovint i que es va portant d'un punt a un altre.

Com es mesura en un punt

  1. Apunteu on és el gateway: planta, alçada i si és a l'interior o a l'exterior. Si el gateway es mou, el mapa ja no serveix.
  2. Situeu el node de prova al punt, a l'alçada on aniria un node de veritat.
  3. Deixeu-lo uns minuts i mireu a la vista de trames en directe l'RSSI i l'SNR de diversos missatges.
  4. Apunteu el valor habitual, no el millor: el senyal varia una mica d'un missatge a l'altre.
  5. Si no arriba cap missatge en uns minuts, apunteu-ho com a «sense cobertura».

Com es fa el plànol

  1. Feu una taula amb totes les mesures: punt, zona, RSSI, SNR i valoració.
  2. Marqueu cada punt al plànol amb un color: verd per a bo, groc per a just i vermell per a feble o sense cobertura.
  3. Marqueu també la posició del gateway amb què heu mesurat.
  4. Busqueu les zones en vermell o groc: és on caldrà un gateway més a prop o un canvi d'ubicació.
RecordeuUn mapa de cobertura només és vàlid per a la posició del gateway amb què s'ha fet. Si proposeu una ubicació nova, les mesures us serveixen per preveure, no per assegurar.

Proveu-ho

Classifiqueu aquestes lectures d'un node de prova.

    Comproveu-ho

    Responeu en equip.

    1. Un node envia un missatge i hi ha dos gateways a prop. Què passa?

      Els nodes no es connecten a cap gateway concret: qualsevol gateway que els senti en reenvia el missatge, i el servidor descarta els duplicats.

    2. Quina d'aquestes lectures d'RSSI és la més forta?

      L'RSSI és negativa: com més a prop de zero, més fort arriba el senyal.

    3. Una lectura té RSSI −95 dBm i SNR −12 dB. Com la valoreu?

      Encara que l'RSSI sigui bo, un SNR per sota de −10 dB vol dir que el senyal amb prou feines destaca del soroll.

    4. El servidor diu que el gateway està connectat. Ja podeu dir que funciona?

      Connectat vol dir que parla amb el servidor. La prova que rep la ràdio és veure arribar trames.

    5. Heu fet un mapa amb el gateway a la planta baixa i després el pugeu a la teulada. Què passa amb el mapa?

      Un mapa de cobertura sempre és el mapa d'un gateway en una posició concreta.
