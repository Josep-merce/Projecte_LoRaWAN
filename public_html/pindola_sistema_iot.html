Com funciona un sistema IoT?

Després d'aquesta píndola sabreu quines peces formen el sistema que construireu i com viatja una dada des del sensor fins a la pantalla.

Què és l'IoT?

IoT vol dir Internet of Things, en català Internet de les coses. Són objectes que mesuren alguna cosa del seu entorn i envien aquesta informació perquè la puguem consultar des de qualsevol lloc.

Un termòmetre normal només us diu la temperatura si el mireu. Un termòmetre IoT l'envia cada pocs minuts a un servidor, on queda guardada, es pot veure en un gràfic i, si cal, us avisa.

Un sistema IoT converteix el que passa en un espai en dades que es poden consultar i fer servir per decidir.

Les quatre peces

Tots els sistemes del projecte, de qualsevol zona, estan formats per aquestes quatre peces:

1 · El node

És el dispositiu que col·locareu a la zona. Està format per:

  • una placa (un petit ordinador que executa un programa);
  • un o diversos sensors;
  • una ràdio LoRa per enviar les dades;
  • una alimentació: endoll o bateria.

2 · El gateway

És una antena que escolta els missatges de tots els nodes que té a l'abast i els reenvia al servidor per Internet.

Un sol gateway pot donar servei a molts nodes. A l'institut, amb un de sol n'hi pot haver prou per a totes les zones.

3 · El servidor

Rep els missatges dels gateways, comprova de quin node venen, els descodifica i guarda les dades en una base de dades.

També sap quins nodes estan registrats a la xarxa: un node que no hi estigui donat d'alta no hi pot enviar res.

4 · El panell

És la part que veuen les persones: gràfics i indicadors amb les dades de cada zona.

A més, pot enviar alertes automàtiques quan una dada supera un límit, per exemple un missatge al mòbil.

Per què LoRaWAN?

LoRaWAN és una manera de comunicar-se per ràdio pensada per a sensors. LoRa ve de Long Range (llarg abast) i WAN de Wide Area Network (xarxa d'àrea extensa).

Els sensors no necessiten enviar gaires dades, però sí fer-ho des de llocs on potser no arriba el wifi i sense haver de canviar la bateria cada setmana. Comparem-lo amb altres tecnologies que ja coneixeu:

El que heu de recordar

  • Arriba lluny: travessa parets i pisos d'un edifici.
  • Consumeix molt poc: un node pot funcionar mesos o anys amb piles.
  • Missatges petits: números, no fotos ni vídeos.
  • No és continu: el node envia cada cert temps, no a cada segon.

Comproveu-ho

Responeu en equip. Si us equivoqueu, llegiu l'explicació i torneu-ho a provar.

  1. Quina peça rep els missatges per ràdio dels nodes?

    El gateway és l'antena que escolta els nodes i reenvia els missatges al servidor.

  2. Per què fem servir LoRaWAN i no wifi per als sensors?

    Els sensors envien poques dades, però han d'arribar lluny i gastar poca bateria. Això és el que ofereix LoRaWAN.

  3. Un node pot enviar una fotografia de l'aula pel sistema?

    LoRaWAN està pensat per a missatges molt petits: uns quants números, no imatges. I així, a més, no es recullen dades de les persones.

  4. On es guarden les dades que envia el node?

    El gateway només les reenvia. És el servidor qui les descodifica i les guarda perquè el panell les pugui mostrar.
