PROJECTE LORAWAN

Espais que parlen

Sensors repartits per l'institut que envien dades sense fils per una xarxa LoRaWAN. Cada equip fa parlar una zona: què hi passa, quan cal actuar i qui ho ha de saber.

Començar per la Fase 1 Veure la presentació

El camí de les dades

  1. MesurarEl node llegeix el sensor de la zona: temperatura, CO₂, llum, presència…
  2. EnviarPer LoRaWAN: ràdio de llarg abast i poc consum, paquets petits cada cert temps.
  3. RebreEls gateways capten els missatges i els passen al servidor de xarxa.
  4. Mostrar i avisarUn panell amb les dades de totes les zones i alertes quan cal actuar.
